# Deep Learning

**Level:** 🟡 Intermediate  
**Prerequisites:** Python, data handling, basic ML, and useful linear algebra intuition

## Learn

- Tensors and neural network layers
- Forward pass, loss, backpropagation, and gradients
- Optimizers and learning-rate schedules
- Regularization and augmentation
- CNNs for images
- Sequence models and attention
- Transformers
- PyTorch training loops

## 💻 Try it

Train a tiny neural network on a simple dataset. Change one thing at a time — learning rate, hidden size, or regularization — and record what happens.

## IOAI connection

Deep learning becomes especially useful when the data is complex, high-dimensional, or unstructured. The key competition skill is adapting a model to the task and constraints.

## ✅ Move on when...

- You can explain forward pass, loss, and backpropagation.
- You can train a small PyTorch model and debug it.
