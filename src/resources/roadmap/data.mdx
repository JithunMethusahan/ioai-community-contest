# Data & Tools

**Level:** 🟢 Beginner  
**Prerequisites:** Basic Python

## Learn

- NumPy arrays and vectorized operations
- Pandas tables and data cleaning
- Matplotlib for plots
- Jupyter notebooks
- Shapes, types, missing values, distributions, and simple exploratory analysis

## ⭐ Recommended resources

- [NumPy Learn](https://numpy.org/learn/)
- [Pandas Getting Started](https://pandas.pydata.org/docs/getting_started/index.html)

## 💻 Try it

Take a CSV dataset. Load it, inspect its shape and columns, find missing values, calculate basic statistics, and make two useful plots.

## IOAI connection

Strong data handling often matters more than a complicated model. You need to understand what the data actually contains before training anything.

## ✅ Move on when...

- You can load and inspect a dataset quickly.
- You can manipulate columns and arrays without getting lost.
- You can make a simple plot and explain what it shows.
