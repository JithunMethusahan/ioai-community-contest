# Python

**Level:** 🟢 Beginner  
**Goal:** Be comfortable reading and writing small Python programs.

## Learn

- Variables, numbers, strings, lists, dictionaries, sets, and tuples
- `if`, `for`, `while`, functions, and imports
- Reading files and using libraries
- Basic classes only when needed
- Debugging and reading error messages

## ⭐ Recommended

[Python Tutorial](https://docs.python.org/3/tutorial/) — the official tutorial. You do not need to memorize Python; learn by writing programs.

## 💻 Try it

Write a program that reads a list of numbers and prints the mean, minimum, maximum, and number of values.

## IOAI connection

Python is the main language you will use for data loading, experiments, model training, and submissions.

## ✅ Move on when...

- You can write a small program without copying every line.
- You can use functions and dictionaries comfortably.
- You can install/import a library and understand a traceback.
