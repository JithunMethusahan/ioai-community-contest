# Machine Learning

**Level:** 🟡 Intermediate  
**Prerequisites:** Python + basic data work

## Learn

- Regression and classification
- Decision trees and ensemble methods
- Clustering and dimensionality reduction
- Features and preprocessing
- Train/validation/test splits
- Metrics and error analysis
- Overfitting, regularization, and cross-validation
- Model selection and simple baselines

## ⭐ Recommended

[ML Foundations](../syllabus/foundations-of-ml) — our explained guide covering the core syllabus topics.

## 💻 Try it

Pick a small tabular dataset. Build a simple baseline, choose a validation split, train two different models, compare the metric, and explain why one worked better.

## IOAI connection

Many IOAI tasks reward careful data analysis, feature engineering, validation, and choosing a sensible baseline before using a larger model.

## ✅ Move on when...

- You can build and evaluate a complete small ML pipeline.
- You understand overfitting and data leakage.
- You can choose a metric and explain your validation strategy.
