# Mathematics for AI

**Level:** 🟢 Beginner → 🟡 Intermediate  
**Prerequisites:** Basic Python helps, but most ideas can be learned alongside ML.

## Learn

- Probability and conditional probability
- Mean, variance, distributions, and basic statistics
- Vectors, matrices, dot products, and matrix multiplication
- Derivatives, gradients, and partial derivatives
- Optimization and gradient descent intuition

You do **not** need to become a mathematician first. Learn the math when it explains something you are coding.

## ⭐ Recommended

[3Blue1Brown — Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra) for visual intuition.

## 💻 Try it

Implement the dot product of two vectors using a Python loop, then compare it with NumPy.

## IOAI connection

Math helps you understand why models, losses, gradients, probability scores, and optimization behave the way they do.

## ✅ Move on when...

- You understand what a vector and matrix represent.
- You can explain a gradient in simple words.
- You understand probability, averages, variance, and common evaluation metrics.
