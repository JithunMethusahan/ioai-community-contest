# Resource Guidelines

This project is community-curated. The goal is **minimum resources, maximum value** — not a giant list of links.

## What makes a good resource?

Prefer resources that are:

- Free or easy to access
- Clear for the stated level
- Practical and/or genuinely useful for understanding theory
- Relevant to AI learning or IOAI preparation
- Maintained and reachable
- Better than an existing resource for the same job

## Core vs community resources

The main roadmap should stay small. A resource can be useful without becoming a core recommendation.

- **Core:** one of the resources we actively recommend in the learning path.
- **Community:** useful alternatives, deeper material, or niche resources discovered by contributors.

## Before opening a PR

1. Check whether the resource is already listed.
2. Check whether an existing resource already covers the same purpose better.
3. Test the link.
4. Choose the correct difficulty and topic.
5. Explain why the resource is useful.

## Review checklist

Reviewers should check the link, relevance, quality, accessibility, level, duplication, and whether the description matches the actual resource.

A contribution does not have to be accepted just because it is good. The project may keep the core path intentionally small.
